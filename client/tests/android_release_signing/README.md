# Android release signing configuration

Run against the staged Android project generated by CMake/androiddeployqt:

```sh
python client/tests/android_release_signing/run_gradle_signing_tests.py \
  --project /path/to/build/client/android-build \
  --java-home /path/to/jdk17 \
  --gradle-user-home /path/to/isolated/gradle-cache \
  --out /path/to/new/evidence-directory
```

The runner uses the real Gradle DSL and inert signing values to check unsigned
Release configuration, rejection of partial inputs, store-password fallback and
an explicit key-password override. It preserves spaces in values and records
effective debug/minification flags. It runs offline Gradle `help` tasks only;
APK creation, signing and device acceptance are separate checks. The dependency
cache must already be populated by the Android build preparation.
