No reviewed static bundle has been supplied or activated on a server. With no bundle, the existing Python deployment remains selected; an invalid supplied bundle fails closed.

CLI: `amnezia-collector-route <scope> [--bind]`. Root UID0, fixed /opt/amnezia/client-logs, fixed /usr/bin/docker, fixed four-scope/interface allowlist. No environment/path/CLI override of the privileged executable, metadata root or /proc root. Configurable Adapter/root/UID arguments are C++ test seams only.

Core keeps exact publication IDs, pinned collector image/label/network/mount checks, source StartedAt+network namespace epoch, restart of only the owned collector, exact iptables -C/-A and guarded own-addition rollback. It never restarts the VPN parent. JSON uses official json-c, typed fields, strict UTF8/trailing parsing and bounds4096(binding)/1MiB(inspect), depth32. Duplicate JSON fields retain json-c/Python-compatible last-value semantics; a final ill-typed schema/field rejects. NUL bytes/escapedNUL reject to avoid parser keyaliasing. No handwritten JSON parser.

Native identity instead requires the exact executable/argv and SHA label, with SHA-256 verified from the bound running PID executable inode. Source epoch/namespace and collectorPID/namespace are checked again after the listener proof. Publication preflight accepts the exact historical legacy missing/null/empty Labels forms; bind and reconciliation retain their stricter identity contract.
